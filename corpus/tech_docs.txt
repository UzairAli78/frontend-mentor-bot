## HTML ESSENTIALS

### HTML5 Semantic Elements
- <header>: Page or section header containing navigation, logos, headings
- <nav>: Navigation links container
- <main>: Main content of the document (only one per page)
- <article>: Self-contained content (blog posts, news articles)
- <section>: Thematic grouping of content with a heading
- <aside>: Sidebar content, tangentially related to main content
- <footer>: Footer of a page or section

### Common HTML Patterns
Form Structure:
<form action="/submit" method="POST">
  <label for="email">Email:</label>
  <input type="email" id="email" name="email" required>
  <button type="submit">Submit</button>
</form>

Accessible Image:
<img src="path/to/image.jpg" alt="Descriptive text for screen readers" width="300" height="200">

### HTML Best Practices
- Always include DOCTYPE: <!DOCTYPE html>
- Use semantic HTML5 elements instead of divs
- Include meta viewport for responsive design: <meta name="viewport" content="width=device-width, initial-scale=1.0">
- Add lang attribute to html tag: <html lang="en">
- Use aria labels for accessibility

## CSS FUNDAMENTALS

### CSS Box Model
- Content: The actual content (text, images)
- Padding: Space between content and border
- Border: Border around padding
- Margin: Space outside border

box-sizing: border-box; // Makes width include padding and border

### Flexbox Quick Reference
.container {
  display: flex;
  flex-direction: row | column;
  justify-content: flex-start | center | flex-end | space-between | space-around;
  align-items: stretch | center | flex-start | flex-end;
  gap: 1rem; // Space between items
}

.item {
  flex: 1; // Grow to fill space
  flex-shrink: 0; // Prevent shrinking
}

### CSS Grid Quick Reference
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr); // 3 equal columns
  grid-template-rows: auto;
  gap: 20px;
}

// Common patterns:
grid-template-columns: 200px 1fr 200px; // Fixed sidebars, flexible center
grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); // Responsive cards

### CSS Position
- static: Default, normal flow
- relative: Positioned relative to normal position, keeps space
- absolute: Removed from flow, positioned relative to nearest positioned ancestor
- fixed: Positioned relative to viewport, stays on scroll
- sticky: Switches between relative and fixed based on scroll position

### Modern CSS Features
CSS Variables:

  --primary-color: #3b82f6;
  --spacing: 1rem;
}
.button { background: var(--primary-color); }

Media Queries:

  .container { flex-direction: column; }

### Array Methods (Critical for Interviews)
const numbers = [1, 2, 3, 4, 5];

// map: Transform each element
const doubled = numbers.map(n => n * 2); // [2, 4, 6, 8, 10]

// filter: Keep elements that pass test
const evens = numbers.filter(n => n % 2 === 0); // [2, 4]

// reduce: Reduce to single value
const sum = numbers.reduce((acc, n) => acc + n, 0); // 15

// find: Get first element that passes test
const firstEven = numbers.find(n => n % 2 === 0); // 2

// forEach: Execute function for each element
numbers.forEach(n => console.log(n));

### Async JavaScript
// Promises

  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error('Error:', error));

// Async/Await (Preferred Modern Approach)
async function fetchData() {
  try {
    const response = await fetch('https://api.example.com/data');
    const data = await response.json();
    return data;
  } catch (error) {
    console.error('Error:', error);
  }
}

## REACT FUNDAMENTALS

### Component Structure
import React, { useState, useEffect } from 'react';

function MyComponent({ title, onAction }) {
  const [count, setCount] = useState(0);
  
  useEffect(() => {
    // Runs after every render
    document.title = `Count: ${count}`;
    
    // Cleanup function
    return () => {
      console.log('Cleanup');
    };
  }, [count]); // Dependency array
  
  return (
    <div>
      <h1>{title}</h1>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  );
}

export default MyComponent;

## GITHUB DEPLOYMENT

### GitHub Pages Deployment (Vanilla HTML/CSS/JS)

Step 1: Create Repository
- Go to GitHub, create new repository
- Name it: your-project-name
- Initialize without README if you have existing code

Step 2: Push Code to GitHub
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/username/your-project-name.git
git push -u origin main

Step 3: Enable GitHub Pages
- Go to repository Settings
- Scroll to "Pages" section
- Source: Deploy from branch
- Branch: main, folder: / (root)
- Click Save

Step 4: Access Your Site
- URL: https://username.github.io/your-project-name/
- Wait 1-2 minutes for first deployment

### Important Notes for GitHub Pages
- Main HTML file MUST be named index.html
- File paths are case-sensitive
- Use relative paths: ./images/photo.jpg not /images/photo.jpg
- No server-side code (PHP, Python, Node.js) - static files only

### React Deployment to GitHub Pages

Step 1: Install gh-pages
npm install --save-dev gh-pages

Step 2: Update package.json
{
  "homepage": "https://username.github.io/repo-name",
  "scripts": {
    "predeploy": "npm run build",
    "deploy": "gh-pages -d build"
  }
}

Step 3: Deploy
npm run deploy

### Fixing Common Issues
404 on GitHub Pages:
- Ensure index.html is in root directory
- Check branch and folder in Settings > Pages
- Clear browser cache

Images not loading:
- Use relative paths: ./images/pic.jpg
- Check file name case matches exactly
- Ensure images are committed to git

CSS not applying:
- Link with relative path: <link rel="stylesheet" href="./style.css">
- Check file is committed
- Hard refresh browser (Ctrl+Shift+R)

## PERFORMANCE BEST PRACTICES

### HTML Performance
- Minimize HTTP requests
- Use async or defer on scripts: <script src="script.js" defer></script>
- Optimize images (compress, use correct formats)
- Use lazy loading: <img loading="lazy" src="...">

### CSS Performance
- Minimize CSS file size
- Use CSS sprites for small icons
- Avoid expensive properties (box-shadow on animations)
- Use transform and opacity for animations (GPU accelerated)

### JavaScript Performance
- Debounce/throttle event listeners
- Use event delegation for many elements
- Avoid memory leaks (remove event listeners, clear intervals)
- Minimize DOM manipulation (batch updates)
